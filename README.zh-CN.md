## 这是什么

leo-adopus 是一套给 Claude Code 等编程 agent 使用的广告风格库。每个风格提炼一支传奇广告的手法：构图、配色、节奏、文案结构和标志性动作，让 agent 为**你的**产品做出一支让人一眼认出原作的广告。

- **你的产品，传奇的手法。** 产品由你提供，风格提供那支改变了广告史的作品的语法。
- **用代码做，不靠视频模型。** 影片用 HTML、CSS 和 JavaScript 写成，再渲染成 MP4。
- **50 种风格，9 个大类。** 从留白平面广告到连锁反应、屏幕叙事和催泪短片，见[风格索引](styles/README.md)。

## 怎么用（规划中）

1. 把插件装进你的编程 agent。
2. 描述你的产品并选一个风格，例如：
   `给我的咖啡磨豆机做一支 30 秒的 silhouette-dancers 广告。`
3. agent 会先问几个问题、给出分镜，再渲染成片。

## "像"的规则

每个风格的目标都是让人一眼认出原作。识别度来自手法，所以我们保留手法：

| 保留：手法 | 替换：素材 |
|---|---|
| 构图和镜头语言 | 原片画面 |
| 配色体系 | 原曲和音效 |
| 节奏和剪辑 | 原文案原句 |
| 文案结构 | 品牌名、logo 和原产品 |
| 标志性动作 | 真人肖像 |

每个风格文件都会写明具体保留什么、替换什么。
