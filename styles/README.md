# Style index

50 styles in 9 families. Each style lives in `styles/<slug>/STYLE.md`.

**Difficulty** is how well the style can be made in code alone:
★★★ code does it well · ★★ needs some illustration or assets ·
★ the original relies on live actors and will be made as an illustrated version.
